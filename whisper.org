* whisper 流程
目的是为了下载 ytd视频，并使用 whisper 生成字幕，并且通过本地大模型生成中英对照的字幕

** whisper 安装
切换到master 分支后 git pull 拉取最新， 并切到最新 release 分支
**** 编译 nvidia 支持的版本

#+begin_src bash
  cmake -B build -DGGML_CUDA=1
  cmake --build build -j --config Release
#+end_src

** 下载模型
make -j large-v3-turbo


** ffmpeg 生成音频

#+begin_src bash
  ffmpeg -i input.mp3 -ar 16000 -ac 1 -c:a pcm_s16le output.wav
#+end_src
一般为多个视频， 生成多份音乐, whisper-cli 目前仅适用于 16位 WAV 文件

#+begin_src bash
  for f in *.mp4 *.mkv *.avi *.webm; do [[ -f "$f" ]] && ffmpeg -i "$f" -ar 16000 -ac 1 -c:a pcm_s16le "${f%.*}.wav"; done
ls#+end_src

** 生成 srt 通过颜色输出可信度

#+begin_src bash
  ./build/bin/whisper-cli -m models/ggml-base.en.bin -f samples/gb0.wav --print-colors
#+end_src

** 生成 srt 文件
#+begin_src bash
  whisper-cli -m ~/Development/whisper.cpp/models/ggml-large-v3-turbo.bin -f bpe_1_LLM_Tokenizer_in_C.wav --language en --output-srt > bpe_1_LLM_Tokenizer_in_C.srt
#+end_src

**  llama.cpp 安装

为 cuda 编译
#+begin_src bash
  cmake -B build -DGGML_CUDA=ON -DLLAMA_OPENSSL=ON
    cmake --build build --config Release -j 32
#+end_src

***  python  绑定

下载 llama-cpp-python
#+begin_src bash
  CMAKE_ARGS="-DGGML_CUDA=on" pip install llama-cpp-python
#+end_src
