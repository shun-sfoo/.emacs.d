** gf2 bitmap viewer 解析方式

代码 (~/.WorkSpaces/gf-master/windows.cpp:867)：
#+begin_src c
uint8_t pixel[3] = {
    (uint8_t) (display->bits[i] >> 16),  // bit 23~16 → 显示为 R
    (uint8_t) (display->bits[i] >> 8),    // bit 15~8  → 显示为 G
    (uint8_t) display->bits[i]              // bit 7~0   → 显示为 B
};
#+end_src

gf2 解析映射（小端序）：
| gf2 代码 | bit 范围 | offset | 字段 |
|----------|---------|--------|-------|
| >> 16 | 23~16 | 2 | r |
| >> 8 | 15~8 | 1 | g |
| & 0xFF | 7~0 | 0 | b |

** 构造 uint32_t 像素的正确写法

*** 推荐：一条写法
#+begin_src c
uint32_t pixel = (a << 24) | (r << 16) | (g << 8) | b;
#+end_src

*** 分步写法（用 |=
）
#+begin_src c
uint32_t pixel = 0;
pixel |= b;
pixel |= (g << 8);
pixel |= (r << 16);
pixel |= (a << 24);
#+end_src

** 错误写法分析

| 写法 | 问题 |
|------|------|
| pixel = x \| y | 用 = 赋值会覆盖之前累积的值 |
| pixel = (pixel << 8) \| g | 左移导致之前字段位置全乱 |
| pixel \|= (g << 8) | ✓ 在原值基础上正确累积 |

验证 (b=2, g=3, r=4, a=5)：

| 步骤 | 错误写法 | 正确写法 |
|------|---------|---------|
| 1 | 0\|2 = 0x02 | 0\|2 = 0x02 |
| 2 | (2<<8)\|3 = 0x0203 | 2\|(3<<8) = 0x0302 |
| 3 | (515<<8)\|4 = 0x020304 | 770\|(4<<16) = 0x040302 ← 正确 |
| 4 | ... | ...\|(5<<24) = 0x05040302 ✓ |

**注意**：分步写法要写成 `pixel |= (x << shift)` 而不是 `pixel = (pixel << shift) | x`

**移位运算原则**

1. 左移 `x << n`：x 的二进制位左移 n 位，低位补 0
2. 右移 `x >> n`：x 的二进制位右移 n 位，低位丢弃
3. `|` (OR)：有 1 则 1，用于累积
4. `=` 赋值：覆盖之前的结果（区别于 `|=`）
5. 优先级：`<<` > `|` > `=`，所以 `(g << 8)` 要加括号
