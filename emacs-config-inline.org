* 寄存器使用 register

emacs 寄存器 register,  实现特定内容复制到特定寄存器， 当前的修改不影响特定寄存器中的内容

1. 保存选中文本到指定寄存器：
选中区域后按下 ~C-x r s <char>~ （例如  ~C-x r s a~ ，表示保存到寄存器 a）。

2. 读取/粘贴指定寄存器的内容：
按下 ~C-x r i <char>~ （例如 ~C-x r i a~ ，将寄存器 a 中的文本插入到光标处

** 属性解释

`:config` 中的代码在包加载之后才能被加载
`:init` 在包前执行的代码
`:custom` 类似于通过 custom-set-variable 设置

  (use-package repeat
    :ensure nil
    :hook (after-init . repeat-mode)  ;; 按完 C-c l n 后只需按 n/p 即可连续跳转
    :config
    (defvar eglot-error-repeat-map  ;; 定义 n/p 分别对应 next/prev error
      (let ((map (make-sparse-keymap)))
        (define-key map "n" #'flymake-goto-next-error)
        (define-key map "p" #'flymake-goto-prev-error)
        map)
      "Keymap to repeat flymake error navigation.")
    (put #'flymake-goto-next-error 'repeat-map 'eglot-error-repeat-map)  ;; 挂到 repeat-map 属性，这是 repeat-mode 识别可重复命令的标准做法
    (put #'flymake-goto-prev-error 'repeat-map 'eglot-error-repeat-map))
